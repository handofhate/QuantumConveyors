# Quantum Conveyors changelog

## 1.1.0

- Replaced the temporary puck-style adapter appearance with the industrial gateway model.
- Tuned the gateway placement, orientation, size, materials, trim, and modeled LED placement.
- Added red, yellow, and green adapter states with matching flashing behavior.
- Added a directional LED light and a soft colored halo effect.
- Fixed gateway collision so the model blocks the player from every side without trapping the player inside.
- Removed the temporary coordinate ruler/debug gizmos from the release build.
- Improved the channel configuration window, including scrolling, channel creation/deletion, renaming, assignment/unassignment, and input focus handling.
- Added `E`, Escape, and right-click menu closing, while preserving `E` for channel names when the rename field is focused.
- Improved interaction targeting around the full gateway model.
- Corrected the collision mesh winding that caused one-way collision behavior.
- Kept endpoint placement and channel behavior compatible with existing saves.

## 1.0.0

- Initial public release of Quantum Conveyors.
