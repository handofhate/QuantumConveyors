# Contributing

Bug reports, ideas and pull requests are welcome: [open an issue](https://github.com/handofhate/QuantumConveyors/issues/new/choose).

## Building

Needs the .NET 6+ SDK and the game with BepInEx (run once, so `BepInEx/interop` exists) and MoonFramework installed;
the project compiles against them.

- Windows: `./build.ps1` (`-Install` copies the DLL into the game; `-MoonSweepersGameRoot` if the game isn't in Steam's
  default folder)
- Linux: `./build.sh` (`--install`; `MOONSWEEPERS_GAME_ROOT` for another folder)

Output: `src/QuantumConveyors.Plugin/bin/Release/net6.0/QuantumConveyors.dll`.

## Releases

See [RELEASE_AUTOMATION.md](https://github.com/handofhate/QuantumConveyors/blob/main/RELEASE_AUTOMATION.md): bump `PluginVersion`, add a matching `Version x.y.z`
section to `CHANGELOG.md`, push, and publish a GitHub release with the tag `vx.y.z`. The workflow builds the zip,
attaches it, and updates Nexus.

## Docs

- The website is `docs/index.html`; the API page `docs/api.html` is generated by `python3 tools/api.py` from
  `Http.cs` (HttpHelp) and `docs/endpoints.toml`. Run it after changing a request. GitHub Pages publishes `docs/`.
- The wiki is written in `wiki/` and published by `.github/workflows/wiki.yml` on every push to `main`
  (`tools/wiki.py` fills in the changelog and the API reference). Edit the files in `wiki/`, not the wiki itself: it's
  overwritten.
